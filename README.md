# 森日日｜MORI HIBI

一個可直接在瀏覽器執行的日文學習 Web App 原型。

## 已完成模組
1. 完整五十音：平假名、片假名、濁音／半濁音、拗音；具備 TTS 聽音、瀏覽器日語語音辨識、Canvas 手寫練習與學習進度。
2. 單字學習：情境分類、搜尋、日文讀音、羅馬字、中文意思、例句、發音與已學紀錄。
3. 文法 25 章：N5 → N1，從禮貌體、助詞、て形一路到 N1 書面語與篇章語感。
4. 常用日語對話：12 個情境，含日文、中文、羅馬拼音、語音播放與跟讀。
5. 翻譯：任意語言輸入 → 日文，自動偵測；可朗讀日文結果。
6. JLPT：N5～N1 可選，每次 30 題，交卷後計分與逐題解析。
7. LocalStorage：自動保留五十音、單字、文法章節與最高測驗成績。

## 啟動方式
最簡單：直接雙擊 `index.html`。

若瀏覽器限制語音或 API，建議在資料夾內啟動簡易本機伺服器：

```bash
python -m http.server 8080
```

然後開啟：
`http://localhost:8080`

## 語音功能
使用瀏覽器 Web Speech API。
- TTS（日文朗讀）：Chrome / Edge 通常可直接使用。
- 語音辨識：Chrome 支援度較佳，且可能要求麥克風權限與 HTTPS / localhost。

## 翻譯功能
原型為了讓使用者能立即測試，前端採公開 Google Translate 端點。
**正式產品不建議直接依賴非正式公開端點。**
商用版應改為後端 API，串接：
- Google Cloud Translation
- DeepL API
- Azure AI Translator
- 其他正式翻譯服務

如此可加入 API 金鑰保護、流量限制、日誌、成本監控與錯誤重試。
